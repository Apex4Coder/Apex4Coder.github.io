Main project

ClodKey — one key, any editor

Some API stations accept requests only in the Claude CLI format. ClodKey's Zoo Bridge translates that format, so the same key works as a regular provider in Zoo Code / Roo Code.

ClodKey MIT · Windows

  • Tray key manager for Claude CLI — no installer, no console windows
  • Profiles with a locked System default, one-click apply
  • Keys encrypted with Windows DPAPI
  • Built-in model check — see what the station serves right now
  • Light / dark, English by default · ru · zh · es
